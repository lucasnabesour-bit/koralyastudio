# Domaine Yin & Yang — Présentation indépendante

Présentation publique autonome : village 3D, hébergements et réservations fictives, marché, vélos, terrasse, réseau social et gestion du logement.

Le code publié ne contient aucune donnée réelle de riverain ni secret serveur. L’application est une démonstration React exécutée dans le navigateur, sans connexion à un service d’identité. Ses essais s’effacent quand l’aperçu est quitté ou rechargé. Les installations physiques restent conceptuelles. Les formulaires n’envoient aucune demande réelle.

## Hébergement

Publier le dossier `dist` comme site statique. Les fichiers sont déjà construits ; aucune installation de dépendance n’est nécessaire pour servir le site. Les sources de l’application sont dans `client/`.

## Vérification

Conversion du composant de démonstration vers Vite, conservation des modules et des images, aucune migration des données privées. La version indépendante est isolée sur une branche dédiée, sans modifier la branche principale ni l’ancien hébergement.
