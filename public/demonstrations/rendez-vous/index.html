Pour un vrai projet

Un agenda partagé, les règles métier, les messages de confirmation et les droits d’accès doivent être connectés et testés. Cette fonction avancée est sur devis, distincte de l’offre vitrine de lancement.

Ce que cet exemple te permet de vérifier.

Est-ce une réservation pour un vrai professionnel ?

Non. Toutes les disponibilités et confirmations sont fictives. Aucun institut, artisan ou client réel n’est associé à cette démonstration.

Pourquoi un créneau peut-il devenir indisponible ?

Deux personnes peuvent choisir la même heure. Le serveur local de démonstration n’accepte qu’une réservation active par créneau. La deuxième demande reçoit un refus et doit choisir une autre heure.

Que se passe-t-il si je ferme cette page ?

En mode onglet, tout est réinitialisé. Avec le serveur local, les réservations fictives restent dans sa base SQLite ; la clé d’annulation ne reste que dans cette page. Cette démo n’a pas de compte client ni de récupération d’accès.

Une annulation retire-t-elle l’événement de mon téléphone ?

L’annulation libère le créneau de démonstration. Si tu as importé le fichier fictif dans ton calendrier, supprime aussi cet événement manuellement.
